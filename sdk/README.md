# SDKs

Language-specific helpers for driving and asserting `pg_sidefx` in tests and applications.

| Path | Role |
|------|------|
| [`typescript/`](typescript/) | TypeScript / Node (`index.ts`, Vitest integration tests) |
| [`rust/`](rust/) | Rust crate (`cargo test` from that directory) |

The PostgreSQL extension itself lives in [`../extension/`](../extension/).
